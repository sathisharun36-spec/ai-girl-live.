
# AI Girl Live

An AI-powered virtual female YouTube livestream host.

## Features
- Realistic fictional female avatar
- Automatic English speech
- AI-generated conversations
- Talking facial animation
- YouTube Live streaming through OBS

## Technology
- GitHub - Project source code
- AI language model - Conversation generation
- Text-to-Speech - English voice
- Talking Avatar - Facial animation
- OBS Studio - Broadcasting

## Development stages
1. Create virtual character
2. Generate English voice
3. Animate the character
4. Connect OBS
5. Broadcast on YouTube

## Important
The virtual character will be clearly presented as AI-generated.
